# Be The Boss Network — Redesign Prototype

A clickable, self-contained mockup of the modernized "be your own boss" platform.
**No build step, no internet required** (fonts/styles degrade gracefully offline).

## How to open
Double-click **`index.html`** — it opens in your browser. Then click through:

| Page | What it shows |
|---|---|
| `index.html` | Homepage — hero + search, 5 category tiles, featured opportunities, how-it-works, trust proof, newsletter |
| `directory.html` | Browse/search with filters (category, budget, location, rating, trust signals) and opportunity cards |
| `company.html` | Company page — verified reviews, startup-cost breakdown, pros/cons, gallery, and the **lead-capture form** (the monetization hook) |

Everything is linked, responsive (resize the window), and accessible.

## Design system
- **Colors:** Navy `#0D2A4D` (trust) · Emerald `#10B981` (action) · Gold `#F4B740` (premium/verified) on slate neutrals
- **Type:** Plus Jakarta Sans (headings) + Inter (body)
- **Files:** `assets/styles.css` (design system) · `assets/app.js` (interactions)

## Note
All companies, logos, reviews, and figures are **illustrative sample data** (e.g. "Sunrise Smoothie Co." is fictional) used to demonstrate layout — not real listings.

See `../modernization-plan.md` for the architecture and build plan behind this design.
